# Project Overview

This is a Next.js project bootstrapped with `create-next-app`. It is a web application built with TypeScript, React, and Tailwind CSS. The project is configured with a basic file structure and includes a theme provider for managing light and dark modes.

## Building and Running

To get started with the development server, run the following command:

```bash
npm run dev
```

Other available scripts:

*   `npm run build`: Creates a production-ready build of the application.
*   `npm run start`: Starts the production server.
*   `npm run lint`: Lints the codebase using ESLint to enforce code quality.

## Development Conventions

*   **TypeScript:** The project uses TypeScript with strict mode enabled, ensuring type safety and code quality.
*   **Linting:** ESLint is configured to maintain a consistent code style.
*   **Path Aliases:** The project uses path aliases, allowing for absolute imports from the root directory (e.g., `@/components/theme-provider`).
*   **Styling:** The project uses Tailwind CSS for styling.
